# Bundled font notices

Comet embeds the following font software in its desktop binary:

- Geist and Geist Mono, copyright The Geist Project Authors, sourced from
  `vercel/geist-font` release `v1.7.2`.
- The KaTeX math fonts (`katex/KaTeX_*.ttf`), copyright Design Science, Inc.
  and Khan Academy, sourced from the KaTeX project as redistributed by the
  `ratex-katex-fonts` crate `0.1.14`. They draw LaTeX math in Markdown.

All of these families are distributed under the SIL Open Font License 1.1. The
complete license texts supplied by the upstream projects are included beside
this notice (`Geist-OFL.txt`, `KaTeX-OFL.txt`).
