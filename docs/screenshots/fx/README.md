# fx provider screenshots

Unedited captures of the Linux desktop app built from this branch with
`cargo build -p zeron`, running on Xvfb with Mesa's software Vulkan driver.
The app uses an isolated data directory and the real fx 0.0.15 executable.
No fx account is configured in the capture environment.

- `providers-dark.png`: fx in Providers, with its installed version and CLI setup guidance.
- `providers-light.png`: the same provider in the light appearance.

These captures demonstrate provider discovery and settings. Model selection,
permissions and session restoration are tested with the ACP contract fixture;
they are not screenshots of a model-backed conversation.
